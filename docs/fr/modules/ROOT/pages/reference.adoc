== `StaticFileHandler` — capacités explicites

* MIME auto-detection (26+ types)
* `Last-Modified` / `If-Modified-Since` → 304
* `ETag` / `If-None-Match` → 304
* path traversal protection
* directory index (`index.html`, `index.htm`)
* fallback chain filesystem → classpath
* zero-copy (`FileChannel.transferTo()`) sur filesystem

== Manques connus

[NOTE]
====
* Pas de mode CLI standalone — l'API est uniquement programmatique. Voir `vidocq-docs` pour un launcher type.
* Compression `Content-Encoding: gzip` négociée — non exposée.
* Header conditionnel `X-Robots-Tag` selon environnement — pas natif, à implémenter par filtre.
* Fallback configurable type SPA (`/index.html`) — pas natif.
====

== `StaticFileHandler` — capacités explicites

* MIME auto-detection (26+ types)
* `Last-Modified` / `If-Modified-Since` → 304
* `ETag` / `If-None-Match` → 304
* path traversal protection
* directory index (`index.html`, `index.htm`)
* fallback chain filesystem → classpath
* zero-copy (`FileChannel.transferTo()`) sur filesystem
* `notFoundFile(path)` — fichier servi en 404 (mutuellement exclusif avec `spaFallback`)
* `spaFallback(path)` — mode SPA, sert le fichier en 200 sur 404
* `preferPrecompressed(true)` — sert les sidecars `.br` / `.gz` en priorité quand l'`Accept-Encoding` les inclut

== `Filter` — helpers déclaratifs

* `Filter.addHeader(name, value)` — injecte un header sur chaque réponse.
* `Filter.addHeaderIf(BooleanSupplier, name, value)` — header conditionnel (prédicat évalué per-request).
* `Filter.addHeaderIfEnv(envVar, expectedValue, name, value)` — gate sur une variable d'environnement (typique : `STAGING=true` pour `X-Robots-Tag: noindex`).
* `Filter.gzip()` / `Filter.gzip(threshold)` — compression à la volée négociée via `Accept-Encoding`. Skip si déjà encodé, `Cache-Control: no-transform`, MIME non text-like, ou taille < seuil (1024 par défaut).

== `AcceptEncoding`

* `AcceptEncoding.parse(header)` — liste d'`Entry(name, qvalue)`.
* `AcceptEncoding.accepts(header, coding)` — règle RFC 9110 §12.5.3 (q-values, wildcard, `identity` implicite).

== Plugin Maven : pré-compression

[source,xml]
----
<plugin>
  <groupId>io.vidocq.chappe</groupId>
  <artifactId>chappe-static-index-maven-plugin</artifactId>
  <executions>
    <execution>
      <goals><goal>index</goal></goals>
      <configuration>
        <compress>gzip</compress>            <!-- défaut: none -->
        <compressThreshold>1024</compressThreshold>
      </configuration>
    </execution>
  </executions>
</plugin>
----

Les sidecars `.gz` générés sont indexés dans `META-INF/chappe-static-index.properties` —
servis zero-copy par `StaticFileHandler.preferPrecompressed(true)`.

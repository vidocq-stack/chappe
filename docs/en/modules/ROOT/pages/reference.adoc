== Public packages (`chappe-api`)

* `io.vidocq.chappe.api` — `Server`, `Router`, `Handler`, `Request`, `Response`, `Body`, `StatusCode`, `MimeTypes`, `StaticFileHandler`, `RequestContext`

== HTTP capabilities

* HTTP/1.1 — RFC 9110, RFC 9112
* HTTP/2 — RFC 9113
* TLS 1.3 (and 1.2)
* HTTP/3 / QUIC — `[TODO]` planned
* WebSocket — `[TODO]` planned

== `StaticFileHandler` — explicit capabilities

* MIME auto-detection (26+ types)
* `Last-Modified` / `If-Modified-Since` → 304
* `ETag` / `If-None-Match` → 304
* path traversal protection
* directory index (`index.html`, `index.htm`)
* filesystem → classpath fallback chain
* zero-copy (`FileChannel.transferTo()`) on filesystem

== Known gaps

[NOTE]
====
* No standalone CLI mode — API is programmatic only. See `vidocq-docs` for a sample launcher.
* Negotiated `Content-Encoding: gzip` — not exposed.
* Environment-conditional `X-Robots-Tag` header — not native, implement via filter.
* SPA-style configurable fallback (`/index.html`) — not native.
====

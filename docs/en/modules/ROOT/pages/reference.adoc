== `StaticFileHandler` — explicit capabilities

* MIME auto-detection (26+ types)
* `Last-Modified` / `If-Modified-Since` → 304
* `ETag` / `If-None-Match` → 304
* path traversal protection
* directory index (`index.html`, `index.htm`)
* filesystem → classpath fallback chain
* zero-copy (`FileChannel.transferTo()`) on filesystem
* `notFoundFile(path)` — file served as 404 (mutually exclusive with `spaFallback`)
* `spaFallback(path)` — SPA mode, serves the file as 200 on a missing resource
* `preferPrecompressed(true)` — prefer `.br` / `.gz` sidecars when the client's `Accept-Encoding` allows them

== `Filter` — declarative helpers

* `Filter.addHeader(name, value)` — inject a header on every response.
* `Filter.addHeaderIf(BooleanSupplier, name, value)` — conditional header (predicate evaluated per request).
* `Filter.addHeaderIfEnv(envVar, expectedValue, name, value)` — gate on an env var (typical: `STAGING=true` → `X-Robots-Tag: noindex`).
* `Filter.gzip()` / `Filter.gzip(threshold)` — on-the-fly compression negotiated via `Accept-Encoding`. Skip when already encoded, `Cache-Control: no-transform`, non-text-like MIME, or size below threshold (1024 by default).

== `AcceptEncoding`

* `AcceptEncoding.parse(header)` — list of `Entry(name, qvalue)`.
* `AcceptEncoding.accepts(header, coding)` — RFC 9110 §12.5.3 rules (q-values, wildcard, implicit `identity`).

== Maven plugin: pre-compression

[source,xml]
----
<plugin>
  <groupId>io.vidocq.chappe</groupId>
  <artifactId>chappe-static-index-maven-plugin</artifactId>
  <executions>
    <execution>
      <goals><goal>index</goal></goals>
      <configuration>
        <compress>gzip</compress>            <!-- default: none -->
        <compressThreshold>1024</compressThreshold>
      </configuration>
    </execution>
  </executions>
</plugin>
----

Generated `.gz` sidecars are indexed in `META-INF/chappe-static-index.properties` —
served zero-copy by `StaticFileHandler.preferPrecompressed(true)`.

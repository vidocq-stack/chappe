= What's new
:description: Everything that changed in this component since the {release-version} release.

[.lead]
New in the `{project-version}` development line — everything listed here landed **after the {release-version} release** and is not part of it. Every entry links to the section that documents it, and those sections carry the [.tag-new]#NEW# badge. Each brick of the suite keeps its own page of this kind; xref:home::whats-new.adoc[the ecosystem index] gathers them. When the next release train ships, this page is frozen with it and restarts empty on the dev line.

* xref:concepts.adoc#handler-failure[A handler that throws an error is answered] [.tag-new]#NEW# — a `NoSuchMethodError`, an `AssertionError` or a `StackOverflowError` thrown by a handler is answered `500` (a gRPC call ends `INTERNAL`), as an exception is; the connection used to end without a response, the error printed on the standard error of its thread. Every failure that escapes an HTTP handler is now logged at `WARNING` (CHAPPE-054).
* [.tag-new]#NEW# WebSocket origin policy — `Router.Builder.webSocketOrigins(WebSocketOrigins)`, same-origin by default; a refused origin gets `403`. See xref:reference.adoc#websocket-origins[Reference — WebSocket origin policy].
* [.tag-new]#NEW# Headers on the `101` — `WebSocketUpgrade` takes a `Headers` and `headers()` returns it. See xref:reference.adoc#websocket-upgrade-headers[Reference — WebSocket upgrade headers].
* [.tag-new]#NEW# Bounded WebSocket writes and close handshake — `writeTimeout` bounds the `101` and every frame, 16 KiB at a time, `readTimeout` the wait for the peer's Close; a cut frame write or close wait reports `1006` to `onClose`. See xref:reference.adoc#timeouts[Reference — timeouts].

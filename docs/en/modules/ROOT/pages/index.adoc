= Chappe
:description: Pure Java 25 HTTP/1.1 + HTTP/2 server, virtual threads, zero dependency.

[.lead]
Chappe is a high-performance HTTP server written in pure Java 25. HTTP/1.1, HTTP/2, TLS 1.3, virtual threads, zero runtime dependency. The original optical telegraph reached Strasbourg from Paris in 36 minutes; the Chappe engine aims at comparable figures, at its own scale.

== Why?

Claude Chappe (1763-1805), inventor of the French optical telegraph in 1794 — a network of 556 hilltop stations with articulated semaphores, capable of carrying a message from Paris to Toulon in under 12 minutes when horse couriers took three days. The success was not about complexity: each station did one thing, did it fast, and the protocol between stations was trivial to observe and to repair.

Chappe, the server, follows the same rule. No framework of frameworks. One `Request`, one `Response`, one `Router`. A `StaticFileHandler` to serve directories with zero-copy. A `chappe-http` layer carrying HTTP/1.1 and HTTP/2, shared across the whole Vidocq ecosystem (Cassini for REST, Foy for Servlet).

== At a glance

* **HTTP/1.1, HTTP/2, TLS 1.3** — `chappe-http` layer, no Netty, no Jetty.
* **Virtual Threads (Project Loom)** — one virtual thread per connection, no platform pool.
* **Scoped Values (JEP 506)** — `RequestContext.CURRENT` propagated before each handler, no `ThreadLocal`.
* **Zero-copy I/O** — `FileChannel.transferTo()` for static files.
* **JPMS** — `chappe-api`, `chappe-http`, `chappe-core`, each with its `module-info.java`.
* **45 RFC 9110/9112/9113 tests** — `chappe-conformance` module.
* **62 integration tests** — `chappe-tests` module.
* **Zero dependency** — no transitive logger, no external utility library.
